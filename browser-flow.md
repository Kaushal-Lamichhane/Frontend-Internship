# Browser Flow

1. Browser opens `index.html`.
2. HTML is parsed and the DOM is created.
3. Browser loads `style.css` and applies styles.
4. Browser loads `script.js`.
5. Browser renders the visible page.
6. JavaScript handles the button click and updates the message.

## DevTools Evidence
- Elements: inspect HTML structure.
- Console: check JavaScript output and errors.
- Network: verify HTML, CSS, and JavaScript requests.
